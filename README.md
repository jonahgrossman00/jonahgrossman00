## 🌟 Repository Highlights  

### 1. [StillSafe](https://github.com/jonahgrossman00/jonahgrossman00/tree/main/StillSafe)  
**Objective**: A machine learning tool to predict stillbirth risk using CDC birth and fetal death datasets.  
**Key Features**:  
- Scraped and processed large-scale health datasets, handling missing data through imputation and feature engineering.
- Built and deployed a scalable pipeline using AWS SageMaker, Lambda, and API Gateway.
- Developed a user-friendly Streamlit web app for risk assessment and actionable healthcare insights.

### 2. [SportsBetPro](https://github.com/jonahgrossman00/jonahgrossman00/tree/main/SportsBetPro)  
**Objective**: Predict outcomes in NBA sports betting using machine learning models.
**Key Features**:
- Collected and analyzed historical betting odds, player statistics, and game outcomes.
- Built regression, classification, and LSTM models for time-based learning, achieving over 55% accuracy in win/loss predictions.
- Enabled profitable decision-making by leveraging data-driven insights.

---

### 3. [The Effect of Graduate-Level Higher Education on Women’s Likability](https://github.com/jonahgrossman00/jonahgrossman00/tree/main/The%20Effect%20of%20Graduate-Level%20Higher%20Education%20on%20Women%E2%80%99s%20Likability)  
**Objective**: Explore the impact of higher education on women’s likability in online dating. 
**Key Features**:  
- Conducted a field experiment with 1,800 observations and a simulated Tinder survey.
- Used linear regression models to reveal significant positive effects of education on likability.
- Analyzed sociocultural dynamics of educational attainment influencing dating preferences.

---

### 4. [Do Democrats or Republicans Experience More Difficulty Voting?](https://github.com/jonahgrossman00/jonahgrossman00/tree/main/Do%20Democrats%20or%20Republicans%20Experience%20More%20Difficulty%20Voting%3F)  
**Objective**: Analyze disparities in voting difficulties across party lines. 
**Key Features**:  
- Investigated data from the 2018 ANES with feature engineering to define voter demographics.
- Conducted Wilcoxon rank-sum tests and correlation analysis, uncovering significant voting challenges.
- Identified weak negative correlations between party affiliation and voter difficulty.

---

### 5. [Uber Traffic Speeds in Post-Lockdown World](https://github.com/jonahgrossman00/jonahgrossman00/tree/main/Uber%20Traffic%20Speeds%20in%20Post-Lockdown%20World)  
**Objective**: Predict traffic speeds in a post-COVID world using Uber data. 
**Key Features**:
- Conducted exploratory analysis on traffic speed data and its relation to urban recovery trends.
- Built regression models achieving 90% accuracy in traffic speed predictions.
- Visualized insights to support urban planning and traffic optimization.
